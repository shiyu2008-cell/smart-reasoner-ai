# Better Auth认证系统集成计划

## 项目概览
为现有的AI简历优化工具集成Better Auth认证系统，替换当前的sessionStorage免费试用管理，实现完整的用户认证、免费试用注册和用户管理功能。

## 阶段一：认证系统配置（Backend Architect）

### 1.1 环境配置
- 更新`.env.local`文件，添加Better Auth配置：
  ```
  BETTER_AUTH_SECRET=6RyMeUXTYHZ8CvdeCEbpFOWzeMlzWfeb
  BETTER_AUTH_URL=http://localhost:3000
  DATABASE_URL=file:./auth.db (或配置其他数据库)
  ```

### 1.2 依赖安装
- 安装Better Auth核心包：`better-auth`、`better-auth/react`
- 安装数据库适配器（如SQLite）：`@better-auth/sqlite`
- 安装必要的插件：用户名认证、邮箱验证、密码重置等

### 1.3 Better Auth配置
- 创建`lib/auth.ts`配置Better Auth实例
- 配置用户名认证插件
- 集成邮箱验证和密码重置插件
- 配置会话管理和令牌处理
- 设置用户角色和权限系统

### 1.4 数据库配置
- 设置SQLite数据库存储用户数据
- 创建用户模式（包含试用次数、注册日期等字段）
- 配置数据库迁移

### 1.5 API路由设置
- 创建认证API路由：`/api/auth/[...all]`
- 实现自定义认证端点（如试用注册）

## 阶段二：用户界面设计（Frontend Architect）

### 2.1 登录界面
- 创建`/auth/login`页面
- 设计响应式登录表单（用户名/密码）
- 集成到现有布局的导航栏
- 添加忘记密码链接

### 2.2 免费试用注册界面
- 创建`/auth/register`页面
- 设计吸引人的试用注册表单
- 包含试用条款和条件
- 添加社交媒体登录选项（如需要）

### 2.3 用户状态管理
- 创建认证上下文提供者
- 实现登录状态钩子
- 添加用户菜单和退出功能

### 2.4 现有UI集成
- 更新布局中的登录/注册按钮
- 将免费试用按钮连接到注册页面
- 添加用户头像和下拉菜单

## 阶段三：功能集成

### 3.1 试用次数管理系统
- 修改dashboard页面，从sessionStorage迁移到用户数据库
- 在用户模型中添加`evaluation_remaining`和`optimization_remaining`字段
- 实现试用次数消耗和重置逻辑

### 3.2 路由保护
- 为dashboard页面添加认证保护
- 创建中间件检查用户认证状态
- 实现未登录用户的重定向

### 3.3 试用期管理
- 在用户模型中添加`trial_start_date`和`trial_end_date`
- 实现试用期检查逻辑
- 添加试用到期提醒

### 3.4 用户角色管理
- 定义用户角色：免费试用用户、付费用户、管理员
- 实现基于角色的访问控制
- 为未来付费功能预留接口

### 5.1 生产环境配置

## 实施策略

### 工具和代理分配：
1. **Backend Architect代理**：负责阶段一的认证系统配置
2. **Frontend Architect代理**：负责阶段二的用户界面设计
3. **Debug Coder代理**：负责阶段四的测试和问题修复

### 渐进式集成：
1. 先实现基础认证功能
2. 然后集成到现有UI
3. 最后迁移试用次数管理
4. 分阶段测试确保稳定性

### 回滚计划：
- 保持现有sessionStorage系统作为备份
- 实现功能开关，可快速切换回旧系统
- 详细记录所有更改，便于问题排查
